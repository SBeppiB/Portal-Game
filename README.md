# Portal Game

Unity 6.3 (6000.3.2f1) URP project featuring a custom portal engine (`Portals.Runtime`).

## Quick start
Open the project in Unity Hub with Unity 6.3.2f1. Open `Assets/Scenes/SampleScene.unity`.

## Tests
- EditMode: 102/102 passing
- PlayMode: 95/95 passing

See `Assets/Portals/README.md` for full documentation.

## Omniversal Portal Mechanics (OPM)
New OPM subsystem under `Assets/Portals/Scripts/Runtime/Mechanics` adds Omniversal coordinates, displacement/energy/stability/accuracy calculations, scanner, structural profiles, and formation evaluation. See README section 10.
